# Pamplate-Christmas-Offer

This is a Christmas Sale Promotional Banner created using HTML and CSS.

It displays different BankNifty Advisory Plans like Monthly, Quarterly, Half-Yearly, and Yearly.

Both original prices and discounted prices are highlighted using different colors (black and green).

The special offer period (20th - 25th December) is displayed prominently in red color at the center.

WhatsApp contact numbers are provided at the bottom on a green background for easy customer communication.

The design focuses on images, color highlights, font styling, and proper alignment for an attractive and professional look.
